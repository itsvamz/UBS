# Volunteer Management System

## Overview
This application is a comprehensive Volunteer Management System designed to manage schools, students, volunteers, and school admins. It provides easy access to learning materials, class schedules, and volunteer opportunities. The system includes multiple accessibility features and a recommendation system to improve user experience.

## Pages & Features

### 1. **Open for All**
- **Home Page:**
  - Header, Footer
  - Success Stories
  - Testimonials
  - What's Happening
  - Contact Page (same as web)
- **Search Schools**: Search for schools based on various filters
- **Volunteer Leaderboard**: View the top-performing volunteers
- **Login/Register**: 
  - 3 Pages (Login, Register, Forgot Password)
- **Events Page**: 
  - Filters based on school, time, and date

### 2. **Open for Students**
- **Dashboard**: Personalized overview of student's progress and activities
- **Classes Timeline**: Integrated with Google Calendar to display class schedules
- **Curriculum**: Access the learning materials and syllabus
- **Uploaded Videos**: Watch and access uploaded videos
- **Live Classes Link**: Access links to live classes
- **Reports**: View academic performance reports
- **Assignments**:
  - Submit assignments
  - Track submitted/late submissions
- **Class Notes**: Access notes for each class
- **Feedback**: Provide feedback on classes

### 3. **Open for Volunteers**
- **Dashboard**: Personalized volunteer overview
- **Curriculum of Subject**: Access subject-specific learning materials
- **Downloadable Certificates**: Ability to download earned certificates
- **Interact with Students**: Messaging platform for communication with students

### 4. **Open for School Admin**
- **Dashboard**: Overview of school activities and statistics
- **Upload Curriculum & Topics**: Manage and upload curriculum content
- **Upload Assignments**: Upload assignments for students
- **Reports**: View reports related to student performance and volunteer activities
- **Approve Volunteers**: Review and approve volunteer applications
- **List of Applications**: View a list of pending volunteer applications
- **Add Events**: Manage and add events for volunteers and students

### Accessibility Features
- **Multi-Language Support**: Application is available in multiple languages
- **Chatbot**: Provides assistance and answers common questions
- **Text to Speech**: Converts text content into speech for accessibility
- **Speech to Text**: Allows users to interact with the app using voice
- **High Contrast Mode**: A mode that enhances visibility for users with visual impairments

## Usage

- **School Admins**: Upload curriculum, assignments, and manage volunteer applications.
- **Students**: View curriculum, classes, assignments, and track progress.
- **Volunteers**: Access subject materials, certificates, and communicate with students.

## Future Features
- **Mobile App**: A mobile version of the system for easier access.
- **Advanced Analytics**: Insights on student performance, volunteer activities, and event success.
- **Integration with External Platforms**: Link to external platforms for virtual classes and webinars.
